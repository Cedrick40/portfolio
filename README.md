# Responsive Personal Portfolio Website

A clean, professional portfolio built with HTML5, CSS3 and vanilla JavaScript for the Arrowstack internship.

## Features
- Sections: Home, About, Skills, Projects, Education & Experience, Contact
- Responsive navigation with a hamburger menu on mobile
- Flexbox and CSS Grid layouts; media queries for desktop, tablet and mobile
- Semantic HTML5 elements, skip link, keyboard focus styles
- Contact form with JavaScript validation (name, email format, message length)

## Project structure
```
portfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run locally
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Customise
1. Replace "Your Name", the initials in the logo/avatar, and the About text in `index.html`.
2. Update the project cards and GitHub links.
3. Update the education and contact details.

## Deploy (free)
Push to a public GitHub repository, then enable **Settings → Pages → Deploy from branch (main, root)**.

## Approach and outcome
I used a mobile-friendly layout with Grid for card sections and Flexbox for navigation, a blue/teal/green palette, and a small script for the menu toggle and form validation. The site works across desktop, tablet and mobile widths.
